# Joshva Construction - Dindigul, Tamil Nadu

A modern, responsive, frontend-only website for **Joshva Construction**, a premier civil engineering and turnkey construction company based in **Dindigul, Tamil Nadu**, directed by **Er. M. Joshva Priyan, B.E. (Civil)**. Built using **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🏗️ Project Overview

- **Company Name**: Joshva Construction
- **Head Engineer**: Er. M. Joshva Priyan
- **Location**: Palani Road, Near Collectorate, Dindigul, Tamil Nadu - 624004
- **Track Record**: 126+ Projects Handed Over across Dindigul, Madurai, Trichy, and Tamil Nadu
- **Specializations**: Residential Duplex Villas, Commercial Towers, Industrial PEB Warehouses, and Seismic IS 456 / 1893 Retrofitting

### Key Features
1. **Cinematic Hero Video**: Seamless HTML5 background video playback (`/images/site-timelapse.mp4`) with play/pause toggle controls and high-contrast scrim overlay.
2. **Animated Count-Up System (`CountUp.tsx`)**: Dynamic numbers that animate upward on page load / scroll (0 to 126+ Projects, 0 to 15+ Years, 0 to 110+ Clients, 0 to 99% On-Time Delivery).
3. **No-Backend Enquiry Routing**: Validates inputs client-side, filters spam via hidden honeypot, and directly opens WhatsApp (`wa.me`) or pre-filled `mailto:` email.
4. **Interactive Google Maps**: Real embed focused directly on Dindigul, Tamil Nadu.
5. **Static Site Generation (SSG)**: Fast static generation for all projects with `generateStaticParams`.

## 🚀 Running Locally

```bash
# Start development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
